Description of Assignment 2 - Assignment 2 focuses on applying key concepts in estimation and machine learning through hands-on Python implementation. The lab is divided into three main parts that together develop practical understanding of algorithm design, data analysis, and model evaluation. The first part involves implementing non-linear estimation techniques using Least Squares Estimation (LSE) and Gradient Descent to build a Single Point Positioning (SPP) algorithm for vehicle tracking based on Global Navigation Satellite System (GNSS) data. The second part applies logistic regression for binary classification to predict depression levels among students, introducing learners to data-driven decision-making in a mental health context. The third part explores image recognition by constructing and comparing two neural network models, a Multi-Layer Perceptron (MLP) and a Convolutional Neural Network (CNN), using the MNIST handwritten digit dataset. Throughout the assignment, students are expected to collaborate using Git, maintain clear and consistent code structure, and demonstrate best practices in documentation and version control.
